ΜΗΝΙΑΙΑ ΕΝΗΜΕΡΩΣΗ S&P PORTFOLIO OPTIMIZER

1. Κάνε αποσυμπίεση ΟΛΟΥ του ZIP σε έναν φάκελο.
   Μην τρέχεις το πρόγραμμα μέσα από το ZIP.
2. Χρειάζεσαι Python 3.11 ή νεότερη (python.org), με τον Python Launcher.
3. Κάνε διπλό κλικ στο UPDATE_MONTHLY.bat.
   Την πρώτη φορά εγκαθιστά τις απαραίτητες βιβλιοθήκες.
   Άφησε το παράθυρο ανοιχτό. Η ενημέρωση 500 μετοχών μπορεί να αργήσει.
4. Περίμενε να εμφανιστεί SUCCESS και η τελευταία ημερομηνία τιμών.
   Αν εμφανιστεί UPDATE FAILED, ΜΗΝ ανεβάσεις αρχεία. Στείλε το μήνυμα σφάλματος.
5. Στο GitHub repository, άνοιξε τον φάκελο .portfolio_cache.
   Πάτησε Add file > Upload files. Ανέβασε εκεί το νέο cache.db
   από τον αντίστοιχο φάκελο του υπολογιστή σου και κάνε Commit changes.
   Αν το μέγεθος υπερβαίνει το όριο του browser, χρησιμοποίησε GitHub Desktop.
6. ΜΟΝΟ ΤΗΝ ΠΡΩΤΗ ΦΟΡΑ: αντικατάστησε επίσης το app.py στη ρίζα του repository
   με αυτό του πακέτου. Δείχνει ημερομηνία δεδομένων και προειδοποίηση παλαιότητας.
7. Περίμενε την επανεκκίνηση της εφαρμογής. Αν δεν ανανεωθεί, κάνε Reboot app
   από το περιβάλλον διαχείρισης του Streamlit.

ΤΟΝ ΕΠΟΜΕΝΟ ΜΗΝΑ: επαναλαμβάνεις τα βήματα 3–5 από τον ΙΔΙΟ φάκελο.
Δεν απαιτείται καθημερινό download, GitHub Actions ή εκτέλεση updater στον server.
Μην ανεβάζεις .venv, cache.before_update.db ή cache.new.db στο GitHub.
Το UPDATE_REPORT.json καταγράφει αποκλεισμένες μετοχές και αποτυχίες fundamentals.

ΤΙ ΠΕΡΙΕΧΕΙ ΤΟ ΠΑΚΕΤΟ
Το cache.db είναι το αρχικό snapshot του Μαρτίου. Δεν έχει ήδη ενημερωθεί.
Το updater θα λάβει πραγματικά νέα δεδομένα όταν το τρέξεις με σύνδεση στο internet.
Κατεβάζει προσαρμοσμένες ημερήσιες τιμές μέχρι την προηγούμενη ημερολογιακή ημέρα.
Εβδομαδιαία/μηνιαία δεδομένα παράγονται μόνο για ολοκληρωμένες περιόδους.
Πρώτα δημιουργεί πλήρες νέο snapshot και αντίγραφο ασφαλείας, μετά αντικαθιστά τη βάση.
Έως 5% μετοχές χωρίς επαρκείς/πρόσφατες τιμές μπορούν να αποκλειστούν με καταγραφή.
Έως 10% αποτυχίες fundamentals διατηρούν τα προηγούμενα στοιχεία με προειδοποίηση.
Με μεγαλύτερες αποτυχίες διακόπτει, χωρίς αλλαγή της ενεργής βάσης.

ΠΕΡΙΟΡΙΣΜΟΙ
Διατηρεί τη λίστα μετοχών του αρχικού snapshot. Δεν ενημερώνει αυτόματα
τις εισόδους/εξόδους του S&P 500 και δεν παρέχει point-in-time index membership.
Το earningsGrowth της Yahoo είναι τριμηνιαία μεταβολή κερδών έναντι προηγούμενου έτους,
όχι πρόβλεψη αναλυτών. Το app.py αναγράφει πλέον earnings growth.
Δεν έγινε συνολικός έλεγχος της μεθοδολογίας optimization/backtest.
Η δημόσια εφαρμογή συνεχίζει να διαβάζει αποκλειστικά αποθηκευμένα δεδομένα.

ΕΛΕΓΧΟΙ
Πέρασαν τρεις τοπικοί έλεγχοι: απόρριψη ελλιπών/παλιών τιμών,
καταγραφή μερικής αποτυχίας, διατήρηση βάσης αν αποτύχει η δημοσίευση.
Έγινε έλεγχος σύνταξης Python. Δεν έχει επαληθευτεί πλήρης ζωντανή λήψη Yahoo
ούτε η εγκατάσταση σε Windows σε αυτό το περιβάλλον.
